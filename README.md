# Swarm explore

Exploration for the Apart Swarm Alignment hackathon (Nov 2026): choosing what to work on, then first experiments.

- **`SCOPE.md`:** the scope chosen on Nov 4: scrutinise two papers, J-PACT and Silent Dissent, rather than extend them.
- **`proposals/`, `archive/`:** the first candidate projects and their plans, before the focus narrowed to scrutinising two papers.
- **`resources/`:** sprint notes, paper notes and literature surveys.
- **`projects/jpact/`:** J-PACT (arXiv 2611.02153), colluding agents read through the J-lens: reference guide, summary, and reruns of the shared-text and instruction-split tests.
- **`projects/silent-dissent/`:** Silent Dissent (arXiv 2610.02702), agents giving in to peers: reference guide, summary, prompt walkthrough, redesign notes and an experiment harness.
- **`PRIOR-WORK.md`:** what was done before the hackathon.

The hackathon project that grew out of this is [consulted-bridges](https://github.com/pete-finesse/consulted-bridges).
